## 1. 现状分析

### 1.1 当前语音架构

项目当前使用 **Web Speech API (TTS)** 作为主要语音方案，封装于 `src/composables/useSpeech.js`。

**工作流程：**

```
用户点击朗读
    │
    ├── 1. 尝试加载 /audio/xxx.mp3 预录音频
    │       │
    │       ├── 存在 → 播放 MP3
    │       │
    │       └── 不存在/超时（500ms）→ 回退到步骤 2
    │
    └── 2. Web Speech API TTS
            │
            └── 随机选择系统第一个英文语音 → 播放
```

| 层级 | 分类数 | 单词数 | 句型数 | 音频需求 |

## 2. 问题定位

### 2.1 已修复问题 ✅

**文件：** `src/composables/useSpeech.js`

**修复前：**
```javascript
const enVoice = voices.find(v => v.lang.startsWith('en'))
```

问题：
- 随机选择系统第一个英文语音
- 可能是英式发音，也可能是混合口音
- 不同设备体验不一致

**修复后：**
```javascript
// 明确选择美式英语语音（优先 Microsoft/Apple 美式女声）
const enUsVoice = voices.find(v =>
  v.lang === 'en-US' && (
    v.name.includes('Microsoft') ||
    v.name.includes('Samantha') ||
    v.name.includes('Google') ||
    v.name.includes('Alex') ||
    v.name.includes('Female')
  )
) || voices.find(v => v.lang === 'en-US')
  || voices.find(v => v.lang.startsWith('en'))
```

改进：
- 优先选择 `en-US` 美式发音
- 按优先级选声：Microsoft > Samantha > Google > Alex > Female
- 同步 `utter.lang` 到实际语音的语言代码

### 2.2 根本问题（待解决）

| 问题 | 影响 | 严重程度 |
|------|------|---------|
| Web Speech API 音质机械 | 儿童听着不自然 | 🔴 高 |
| 不同浏览器语音不同 | 体验不一致 | 🟡 中 |
| 离线不可用 | 无网络时 TTS 可能失败 | 🟡 中 |
| 无预录音频 | 所有单词依赖浏览器 TTS | 🔴 高 |

### 3.2 各方案详细说明

#### 方案 A：Web Speech API（当前）

| 维度 | 说明 |
|------|------|
| 优点 | 零成本、零延迟、无需网络 |
| 缺点 | 音质机械、设备间不一致、离线不可靠 |
| 音质 | 浏览器原生 TTS，电子感强 |

#### 方案 B：Google Cloud TTS

| 维度 | 说明 |
|------|------|
| 优点 | 音质优秀（WaveNet）、多种音色 |
| 缺点 | 需要 API Key、有免费额度限制（400万字符/月）、需服务端 |
| 成本 | 免费额度用完后 ¥16/100万字符 |

#### 方案 C：ElevenLabs

| 维度 | 说明 |
|------|------|
| 优点 | 音质最高（AI 拟真）、可定制音色 |
| 缺点 | 免费版仅 1万字符/月、付费 ¥150/月、需联网 |
| 成本 | Free: 1万字符/月；Starter: $5/月 |

#### 方案 D：预录真人录音

| 维度 | 说明 |
|------|------|
| 优点 | 音质完美、情感自然 |
| 缺点 | 成本高（¥20~30/词）、周期长、维护困难 |
| 成本 | 160 词 × ¥20 = ¥3200+ |

#### 方案 E：Edge TTS（推荐）

| 维度 | 说明 |
|------|------|
| 原理 | 使用微软 Edge TTS 引擎，通过 Python 包 `edge-tts` 批量生成 MP3 |
| 优点 | 完全免费、Neural 音质、离线可用、实施简单 |
| 缺点 | 首次生成需要网络、音质略逊于 ElevenLabs |
| 成本 | **¥0** |

## 4. 推荐方案

### 4.1 最终选择：Edge TTS 批量生成 + 浏览器 TTS 回退

**架构：**

```
用户点击朗读
    │
    ├── 1. 尝试播放 /audio/xxx.mp3（预录 Edge TTS）
    │       │
    │       ├── 存在 → 播放 MP3（音质优秀，离线可用）
    │       │
    │       └── 不存在 → 回退到方案 2
    │
    └── 2. Web Speech API TTS（已优化选音逻辑）
            │
            └── 播放（保底方案，确保任何情况下都有声音）
```

**选择理由：**

| 维度 | 说明 |
|------|------|
| 零成本 | 符合项目"完全零费用"定位 |
| 高音质 | Neural TTS 音质远超浏览器原生 TTS |
| 离线可用 | MP3 预加载到 PWA，无网络也能播放 |
| 实施简单 | Python 脚本一键生成，10 秒完成 160 个音频 |
| 可回退 | 保留浏览器 TTS 作为保底 |
| 一致性 | 所有设备听到相同音色 |

### 4.2 Edge TTS 可用美式音色

| 音色 ID | 风格 | 推荐度 |
|---------|------|--------|
| en-US-AriaNeural | 自然女声，温暖 | ✅ 推荐（儿童英语） |
| en-US-AnaNeural | 甜美女声 | ⭐ 备选 |
| en-US-JennyNeural | 清晰女声 | ⭐ 备选 |
| en-US-GuyNeural | 成熟男声 | ❌ 不适合儿童 |

## 7. 风险与回退

### 7.1 潜在风险

| 风险 | 概率 | 影响 | 缓解措施 |
|------|------|------|---------|
| edge-tts 服务不可用 | 低 | 中 | 保留浏览器 TTS 回退 |
| 生成音频音质不满足 | 低 | 低 | 试听后换音色（Ana/Jenny） |
| PWA 包体积过大 | 极低 | 低 | 161 个音频约 2 MB，影响极小 |
| 浏览器兼容性 | 低 | 低 | MP3 格式全平台兼容 |

### 7.2 回退方案

如果 Edge TTS 生成的音频不满意：

**1. 换音色**

修改脚本中 `VOICE` 变量：

```javascript
const VOICE = 'en-US-AnaNeural'  // 换为甜美嗓音
```

**2. 调语速**

调整 `RATE` 变量：

```javascript
const RATE = '-15%'  // 更慢（适合更低龄）
const RATE = '-5%'   // 更快（适合大龄儿童）
```

**3. 回退到方案 A**

删除 `public/audio/` 目录，系统自动使用浏览器 TTS：

```bash
rm -rf public/audio/
```
