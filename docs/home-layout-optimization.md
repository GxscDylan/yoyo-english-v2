# 首页布局优化总结

## 问题
原版首页功能越来越多，导致 iPad 横屏下显示拥挤：
- 底部导航 9 个按钮被截断（Sentences/家长 显示不全）
- 冒险地图 12 个分类节点横向拥挤
- 各区块间距偏大，纵向内容超出

## 优化方案

### 1. 底部导航：9 按钮 → 5 按钮
| 优化前 | 优化后 |
|--------|--------|
| 🔍 Find It | 🎮 游乐场（整合6款游戏） |
| 🎧 Listen | |
|  Memory | |
| 🎈 Pop! | |
| ⚡ Rush | |
| ️ Sort! | |
|  Songs |  Songs |
|  Sentences |  Sentences |
| ️ 家长 |  复习 + 🛡️ 家长 |

- 按钮从 `flex-wrap` 改为 `flex: 1` 平分布局
- 每个按钮图标 + 文字纵向排列，高度 48px
- 不再需要横向滚动，5 个按钮刚好适配 iPad 横屏

### 2. 冒险地图节点精简
| 节点状态 | 显示内容 | 宽度 |
|---------|---------|------|
| 锁定 🔒 | 仅图标 | 48px |
| 已解锁未完成 | 图标 + 名称 + 简化进度 | 48px |
| 当前进行中 | 图标 + 名称 + 场景 + 进度 + GO! | 64px |
| 已完成 ✅ | 图标 + 名称 + 场景 + 进度 | 48px |

- 锁定节点完全隐藏文字，减少视觉干扰
- 非当前/非完成节点隐藏场景名
- 箭头分隔符透明度降低（0.6 → 0.15 锁定节点）

### 3. 间距调整
- 顶部区域 padding：`lg` → `sm`
- 呦呦宽度：`120px` → `100px`
- 冒险地图 padding：`md` → `sm`
- streak/today section：margin/padding 从 `md` 缩小为 `xs/sm`

## 效果
- iPad 横屏下所有功能完整显示
- 底部导航不再被截断
- 冒险地图更清晰，引导用户关注当前进度
- 整体视觉更紧凑，呼吸感更好
